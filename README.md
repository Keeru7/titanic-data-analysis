# Titanic Dataset - EDA and Visualisation

## Project Overview

This project focuses on understanding and exploring the Titanic dataset before applying machine learning.

The dataset was cleaned using Pandas and explored using different visualisations to identify relationships, correlations, and potential outliers.

## Objectives

- Understand the structure of the dataset
- Identify and handle missing values
- Explore relationships between variables
- Create meaningful visualisations
- Identify correlations
- Analyse potential outliers
- Document key findings

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset exploration
- Missing value analysis
- Data cleaning
- Survival rate by gender
- Survival rate by passenger class
- Age distribution by survival
- Age and fare relationship
- Correlation analysis
- Fare outlier analysis

## Key Takeaways

- Survival rates were different between male and female passengers.
- Passenger class showed a relationship with survival rate.
- Age distributions differed between passengers who survived and those who did not.
- Age and fare were explored to understand their relationship.
- The correlation heatmap showed relationships between numerical variables.
- Fare analysis identified potential outliers.

## Dataset

The Titanic training dataset was obtained from Kaggle.

## Conclusion

The analysis provided an understanding of the Titanic dataset through data cleaning and exploratory data analysis. These findings can help in understanding the data before applying machine learning models.
